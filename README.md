# Portafolio de Desarrollador Odoo & Python

Este es un sitio web de portafolio profesional para un desarrollador especializado en soluciones ERP con Odoo y desarrollo backend en Python.

## 📁 Estructura del Proyecto

```
myWeb/
├── index.html          # Página principal - Introducción y especialización
├── project.html        # Página de proyectos - Casos de estudio técnicos
├── contact.html        # Página de contacto - Perfil técnico y formulario
├── css/
│   ├── main.css        # Archivo principal que importa todos los estilos
│   ├── base.css        # Variables CSS, reset y tipografía
│   ├── utilities.css   # Clases de utilidad generales (flex, grid, spacing)
│   ├── layout.css      # Estructura general del sitio (header, main, footer)
│   ├── components.css  # Componentes reutilizables (nav, cards, buttons)
│   └── contact.css     # Estilos específicos de la página de contacto
├── js/
│   └── main.js         # JavaScript compartido (menú móvil, navegación)
├── img/
│   └── cris.png        # Imagen de perfil del desarrollador
└── docs/
    ├── contact.png     # Captura de pantalla de la página de contacto
    ├── home.png        # Captura de pantalla de la página principal
    └── project.png     # Captura de pantalla de la página de proyectos
```

## 🛠 Tecnologías Utilizadas

### Lenguajes y Frameworks
- **HTML5**: Estructura semántica del sitio
- **CSS3**: Estilos modernos con características avanzadas
- **Vanilla JavaScript**: Funcionalidad interactiva sin frameworks

### Características CSS Avanzadas
- **CSS Custom Properties**: Variables para colores, espaciado y tipografía
- **Flexbox & Grid**: Layouts responsivos y flexibles
- **CSS Backdrop Filter**: Efectos de vidrio (glassmorphism)
- **CSS Aspect Ratio**: Relaciones de aspecto consistentes
- **CSS Animations**: Transiciones suaves y microinteracciones

### Tipografía y Iconografía
- **Google Fonts**:
  - Inter: Fuente principal para texto
  - JetBrains Mono: Fuente monospace para código y navegación
- **Material Symbols**: Iconos de Google para elementos UI

### Arquitectura CSS
- **ITCSS-like**: Inverted Triangle CSS para organización modular
- **Mobile-first**: Diseño responsivo comenzando desde dispositivos móviles
- **Utility Classes**: Clases de utilidad para desarrollo rápido

## 🎨 Diseño y UX

### Tema
- **Dark Theme**: Tema oscuro por defecto con paleta de colores profesionales
- **Glassmorphism**: Efectos de vidrio translúcido con backdrop blur

### Interactividad

## 📱 Responsive Design

El sitio está completamente optimizado para:
- **Móviles** (< 768px)
- **Tablets** (768px - 1024px)
- **Desktop** (> 1024px)

### Breakpoints
- `sm:` 640px
- `md:` 768px
- `lg:` 1024px

## 🚀 Arquitectura y Organización

### Por qué esta estructura:
1. **Separación de responsabilidades**: HTML, CSS y JS separados
2. **Mantenibilidad**: CSS modular facilita cambios y debugging
3. **Reutilización**: Componentes y utilidades compartidas
4. **Performance**: CSS organizado reduce duplicación de código
5. **Escalabilidad**: Fácil agregar nuevas páginas y componentes

### Patrón de Organización CSS:
- **Base**: Variables, reset, tipografía base
- **Utilities**: Clases de utilidad atómicas
- **Layout**: Estructura general del sitio
- **Components**: Componentes reutilizables
- **Pages**: Estilos específicos por página

## 🔧 Configuración de Desarrollo

### Requisitos
- Navegador moderno con soporte para CSS Grid, Flexbox y ES6+
- No se requieren dependencias externas (excepto Google Fonts)

### Ejecución
Simplemente abrir los archivos HTML en un navegador web. No requiere servidor local.
